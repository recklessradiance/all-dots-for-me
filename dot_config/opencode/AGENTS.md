# Subagent Delegation

- For every user request, invoke at least one suitable subagent with the task tool whenever that tool and a relevant subagent are available. Do this even for small requests; prefer a brief independent check over skipping delegation.
- For requests with independent workstreams, launch suitable subagents in parallel. Give each a narrow task and ask for actionable findings or a concrete result.
- Use subagents as collaborators, not as a substitute for owning the response: review their results, integrate them, and verify any changes yourself.
- If delegation is unavailable or genuinely inapplicable, proceed directly and briefly note why when it matters.
